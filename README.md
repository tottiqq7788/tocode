# Tocode（app）

macOS 菜单栏文件管理器，Swift/AppKit 原生实现。

## 功能

- 左键菜单栏图标 → 弹出当前根目录树；悬停文件夹展开下级；点击文件或文件夹复制「绝对路径」。
- 右键菜单栏图标 → 功能菜单：读取剪贴板、更改目录、重置初始目录、codex、微信关联、设置、退出。
- 根目录保存在本机；已保存路径不存在时回退 `/Users/admin/Documents`。
- **设置 → 开机自启**（默认关闭）：把 Tocode 登记为系统登录项，开机后自动启动。菜单只显示系统里的实际状态；在系统设置里手动关掉后，下一次打开本菜单会跟着关闭。登记失败或需要批准时不会显示为已开启。
- **设置 → 对调垂直滚轮 / 对调横向滚轮**（默认关闭）：只反转物理鼠标滚轮对应轴向，**不改触控板**（含 Magic Mouse 表面等连续滚动）。不做平滑插值，也不改系统「自然滚动」。启用前请先退出 Mos，否则两边会互相抵消。与快捷键钩子相互独立：滚轮钩子故障不会拆掉 ⌘Q / ⌘X。
- **设置 → 显示/隐藏隐藏文件**：与访达共用 `AppleShowAllFiles`。左键目录树显示隐藏项时访达也显示，反之亦然。覆盖以 `.` 开头的条目，以及带 Finder hidden 属性的条目。
- 在访达中按 `⌘⇧.` 切换后，下一次打开 Tocode 菜单会跟随新状态。
- 从 Tocode 切换该选项会写入访达偏好并重启访达，使显示立即生效；写入或重启失败时恢复原状态。
- **访达目录初始化**（条件显示）：访达里用鼠标恰好选中一个项目时出现，不要求访达仍在前台。选中文件夹则设为左键根目录；选中文件则设为其父级文件夹。无选中、多选、权限失败或路径失效时不显示；点击时会再次校验，失败不改根目录。
- **设置 → x/v移动文件**（默认关闭）：仅当访达是前台应用时接管普通 `⌘X` / `⌘V`。文件上下文中 `⌘X` 会先变成访达复制；剪贴板 `changeCount` 变化且含文件 URL 后进入剪切预备。下一次 `⌘V` 改写为访达原生 `⌥⌘V`，移动到**访达当前窗口的目标目录**，不是 Tocode 的左键根目录。多文件、文件夹、重名冲突、跨卷、iCloud 和权限提示都由访达自己处理。重命名或文本框中的 `⌘X` 仍按文本剪切。其他应用的 `⌘X` / `⌘V` 完全不受影响。
- **设置 → 双击⌘Q**（默认关闭）：全局保护普通 `⌘Q`（不含 Shift / Option / Control）。第一次按下会被吞掉并提示「再次按 ⌘Q 退出 \<应用\>」；只有 2 秒内、目标仍是同一进程时，第二次才放行退出。超时或切换目标后重新计数。这是普通退出，不是强制退出：`⌘⇧Q`、`⌥⌘Esc`、鼠标点菜单「退出」、Dock / 活动监视器退出和 `kill` 都不会被拦截。按住产生的自动重复不算第二次。
- **设置 → ⌘Q强关访达**（默认关闭）：当访达是普通前台，或系统 Command-Tab 切换器当前选中访达时，普通 `⌘Q` 会关闭全部访达窗口并隐藏访达，**不会退出访达进程**。没有打开窗口时也会隐藏。目标无法识别时原样放行。与「双击⌘Q」同时开启时，第一次只提示「再次按 ⌘Q 强关访达」，2 秒内再按一次才关窗隐藏。

## codex（同步项目夹）

- 右键菜单栏图标 → **codex**：显示 Codex 当前选中的本地项目名称与根目录；检测失败显示「未检测到 Codex 项目」。
- **同步项目夹**（默认关闭）：开启后左键目录树每次弹出时跟随 Codex 当前项目的根目录；关闭后恢复手动根目录。
- 开关开启时，「读取剪贴板」「更改目录」「重置初始目录」「访达目录初始化」四项置灰不可点击；关闭后恢复。
- 只读本机 Codex 全局状态文件 `~/.codex/.codex-global-state.json`，绝不写回；状态不可读或没有有效项目时，左键自动回退手动根目录（开关与置灰状态仍以开关为准）。

## 微信关联

- 右键菜单栏图标 → **微信关联 → 绑定微信**：默认浏览器会打开扫码页面。使用具备 iLink Bot 资格的个人微信扫码并确认后，菜单项显示勾选。
- 绑定凭据只保存在 macOS Keychain。应用启动时会自动恢复监听；普通断网、超时或微信服务暂时故障不会取消绑定，只有服务端明确返回 `401/403` 才会清除凭据并通知重新绑定。
- 绑定后再次点击「绑定微信」可重新扫码。新绑定确认并安全保存前，旧绑定仍保持运行；扫码失败或过期不影响旧绑定。
- Tocode 只接收**发给已授权 iLink Bot 的新消息**，不会读取个人微信账号里的其他私聊、群聊或历史记录，也不会调用模型、发送确认或自动回复。
- 收到的文字、语音转写、图片、文件和视频会归档到固定位置 `/Users/admin/Documents/wechat`。只有 iLink 实际提供媒体下载描述时才保存原文件。
- 每天使用一个 `yyMMdd` 目录和一个 Markdown 文件。例如 2026-09-07 写入 `260907/wechat260907.md`；附件按本机收到时间重新命名，既有文件永不覆盖。
- **微信关联 → 文件位置**会创建并在访达打开归档目录。

微信 iLink 目前可能受内测资格与服务端协议变化限制。无法扫码或账号没有入口时，不代表 Tocode 能绕过资格读取普通微信聊天。

## 权限

首次使用「访达目录初始化」时，系统可能请求「控制访达」。请允许；拒绝后该选项不会出现。

开启任一快捷键开关或滚轮对调开关时，只会显式请求**辅助功能**。该授权用于读取 Finder / Dock 切换器焦点，以及创建可拦截、改写按键和滚轮的事件钩子；不会另行申请「输入监控」或独立 PostEvent 权限。关闭访达窗口复用已有的「控制访达」自动化授权：

1. 右键菜单栏图标 → 设置 → 打开对应开关。
2. 若系统打开授权提示，请到「系统设置 → 隐私与安全性 → 辅助功能」中允许 Tocode，再点击一次开关。
3. 事件钩子实际安装成功后，当前菜单项会立即显示 `checkmark.circle.fill`；失败时保持 `circle`。
4. 拒绝授权、钩子创建失败或钩子无法恢复时，开关保持关闭，**所有按键原样放行**，不会锁死键盘或退出通道。

三项快捷键默认关闭；全部关闭时不会安装键盘事件钩子。两项滚轮对调默认关闭；全部关闭时不会安装滚动钩子。

本地构建使用稳定的 designated requirement，避免 ad-hoc 签名默认绑定每次变化的 `cdhash`，导致重新编译后已有的访达自动化授权静默失效。首次从旧构建迁移到稳定签名时仍需重新允许一次；辅助功能授权同样绑定该稳定身份。

## 构建

```bash
bash scripts/build.sh        # 编译并打包到 build/Tocode.app
bash scripts/test.sh         # 运行单元测试
```

## 目录

- `Sources/` 应用源码
- `Tests/` 单元测试
- `Resources/Info.plist` 应用元数据
- `scripts/` 构建与测试脚本
